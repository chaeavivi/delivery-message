# 채아힐링센터 송장 안내 메시지 봇

택배사를 고르고 송장번호만 넣으면 고객에게 보낼 안내 메시지를 만들어 줍니다.
송장 캡쳐 이미지를 올리면 번호를 자동으로 읽어오고, 메시지 안에 배송조회 주소가 함께 들어갑니다.

## 할 수 있는 것

- **택배사 3곳 선택** — 우체국택배 · GS Postbox 택배 · CU 편의점택배
- **취급 품목 버튼 선택** — 자격증 · 자격과정 교재 · 컬러테라피 보드게임(레인보우프리즘 ·
  컬러링코드 · 마인드 보석함) · 컬러테라피 교구재 · 아트테라피 재료
  (여러 개를 함께 고를 수 있고, 목록에 없는 것은 직접 적어도 됩니다)
- **송장번호 입력 2가지** — 직접 입력, 또는 캡쳐 이미지에서 자동 인식
  (사진 선택 · 끌어다 놓기 · <kbd>Ctrl</kbd>+<kbd>V</kbd> 붙여넣기 모두 됩니다)
- **도착 예상일 자동 계산** — 주말과 공휴일을 뺀 영업일 기준
  - 우체국택배: 영업일 기준 익일~2일 이내 발송
  - GS Postbox / CU택배: 영업일 기준 2~3일 이내 배송
- **메시지에서 바로 배송조회** — 송장번호가 들어간 조회 주소가 메시지에 포함되어,
  받는 분이 카카오톡에서 링크만 누르면 바로 조회됩니다
- **문구 편집** — 안내 문구를 직접 고칠 수 있고, 고친 내용은 그 기기에 저장됩니다

## 쓰는 방법

브라우저만 있으면 됩니다. 설치할 것도, 서버도 필요 없습니다.

```bash
npm start          # http://localhost:4173
```

### 휴대폰에서 쓰려면 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. Source 를 `Deploy from a branch`, 브랜치를 이 브랜치 / 폴더는 `/ (root)` 로 지정
3. 몇 분 뒤 나오는 주소를 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다

> 이미지 인식 기능은 처음 한 번 인식 엔진을 내려받기 때문에 인터넷 연결이 필요합니다.
> 직접 입력은 인터넷 없이도 됩니다.

## 고칠 일이 생기면

| 고치고 싶은 것 | 파일 |
| --- | --- |
| 택배사 이름 · 소요기간 · 조회 주소 · 송장 자릿수 | `src/carriers.js` |
| 취급 품목 목록 | `src/products.js` |
| 공휴일 (연도가 바뀌면 여기에 날짜 추가) | `src/holidays.js` |
| 기본 안내 문구 | `src/message.js` 의 `DEFAULT_TEMPLATE` |
| 화면 색·글씨 | `assets/style.css` |

### 공휴일 목록

`src/holidays.js` 에 2026년 전체와 2027년 고정 공휴일이 들어 있습니다.
2027년 설날·추석·부처님오신날처럼 음력으로 정해지는 날은 확정된 뒤 추가해 주세요.
목록에 없는 해는 **주말만 빼고** 계산하며, 화면에도 그렇게 안내됩니다.

### 조회 주소가 바뀌었다면

택배사가 조회 페이지 주소를 바꾸면 `src/carriers.js` 의 `trackUrl` 한 줄만 고치면 됩니다.

## 메시지 문구 직접 고치기

화면 아래 **"메시지 문구 직접 고치기"** 를 열면 문구를 마음대로 바꿀 수 있습니다.

- `{{고객명}}` `{{상품명}}` `{{택배사}}` `{{송장번호}}` `{{발송일}}`
  `{{배송안내}}` `{{도착예상}}` `{{조회링크}}` `{{공휴일안내}}` — 자동으로 채워집니다
- `[[ ... ]]` — 안에 든 값이 비어 있으면 그 부분이 통째로 사라집니다.
  고객명을 안 적었을 때 `님,` 만 남는 것을 막아줍니다
